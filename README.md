# AIRANGE — Learning Nine

Nine medium, self-contained challenges for the individual university CTF. Each challenge has a player ZIP, original art, learning notes, and the strict flag format `AIRANGE{...}`.

AI assistants are prohibited by the competition honor rule. This is an honor-based restriction; offline files cannot monitor participant devices.
